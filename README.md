# Elige_tu_stack

En esta actividad he realizado una introducción al desarrollo web con PHP, diferenciando entre el funcionamiento del cliente y el servidor y entre páginas web estáticas y dinámicas.

También he estudiado el funcionamiento de la infraestructura web, incluyendo Apache, PHP-FPM y Laravel, y las ventajas de utilizar PHP-FPM frente al antiguo modelo CGI.

Por último, he analizado la elección de PHP y Laravel 12, destacando el patrón MVC, la seguridad, la validación de datos y la organización del proyecto.

Además, he realizado una pequeña práctica en PHP que muestra en una página web la fecha y hora actuales, utilizando date() para obtenerlas y htmlspecialchars() para mostrar los datos de forma segura.
